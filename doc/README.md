# Immich Captioner & Distributed Caption Worker

Комплексная система автоматического интеллектуального описания (captioning) и тегирования фотоархива в **Immich** с использованием локальных мультимодальных моделей зрения (VLM — Vision Language Models), таких как **Qwen2.5-VL / Qwen3-VL** через **LM Studio**.

---

## 🎯 Ключевые возможности

1. **Качественные описания на русском языке**:
   - Детальное описание сцены, объектов, действий, локаций и настроения фотографии.
   - Распознавание любого читаемого текста на фото (вывески, документы, надписи, логотипы, номера).
   - Автоматическая генерация поисковых тегов в конце описания (формат `Теги: ...`).
   - Сохранение описания прямо в метаданные ассета в Immich (поле `description`), благодаря чему работает мгновенный умный поиск по архиву.

2. **Два режима работы под любые сценарии**:
   - **Standalone (Прямой режим)**: Единое приложение `ImmichCaptioner.exe`, подключающееся напрямую к Immich API и локальному LM Studio. Идеально для работы на одном мощном ПК.
   - **Distributed Queue (Сетевой / распределённый режим)**: Разделение на **Координатор** (`coordinator.py` на сервере Immich/NAS) и один или несколько **Сетевых Воркеров** (`ImmichCaptionWorker.exe` или `file_worker.py` на ПК с дискретными видеокартами).

3. **Сетевой GUI Воркер (`ImmichCaptionWorker.exe`)**:
   - Современный тёмный интерфейс (CustomTkinter).
   - Живой мониторинг нагрузки GPU и видеопамяти (VRAM).
   - Отображение текущего и последнего обработанного фото вместе с полученным описанием.
   - Счётчики очереди: количество фото в `In/`, активные захваты воркеров, обработано за сессию.
   - Расчёт скорости (фото/мин, фото/час, среднее время генерации).
   - Сворачивание в системный трей (System Tray) и фоновая работа.
   - Возможность автозагрузки вместе с Windows в свёрнутом виде (`--minimized`).
   - Вкладка настроек (выбор сетевой папки, смена ID воркера, тест связи с LM Studio, лимиты GPU).

4. **Интеллектуальный троттлинг (Throttling)**:
   - Воркер автоматически снижает нагрузку или встаёт на паузу, если GPU занят играми или рендером (по порогу утилизации GPU, например >35%).
   - Отслеживание активных «тяжёлых» процессов (`cyberpunk2077.exe`, `blender.exe`, `unrealengine.exe` и др.).
   - Опциональная проверка простоя пользователя (User Idle).

## ⚡ Быстрый старт

### Вариант А: Сетевой режим (Рекомендуется для домашней сети)

1. **На сервере с Immich** (или домашнем NAS):
   - Создайте общую сетевую папку (SMB/Samba), например `\\NAS\CaptionQueue`.
   - Запустите координатор: `python coordinator.py` (или оформите в systemd-сервис: см. [COORDINATOR_SETUP.md](COORDINATOR_SETUP.md)).
   - Координатор сам скачает необработанные превью из Immich в `CaptionQueue/In`.

2. **На рабочей станции / игровом ПК с GPU**:
   - Запустите **`ImmichCaptionWorker.exe`** (или `python ui_worker.py`).
   - В настройках укажите путь к сетевой папке (например, `\\NAS\CaptionQueue`).
   - Убедитесь, что запущен **LM Studio** с загруженной моделью (например, `qwen2.5-vl-7b-instruct`).
   - Воркер автоматически подхватит фото, распознает их и сохранит результат в `CaptionQueue/Out`.
   - Координатор прочитает результат и обновит Immich!

### Вариант Б: Автономный режим (Прямой доступ)

- Если Immich и LM Studio доступны на одной машине, используйте **`ImmichCaptioner.exe`**:
  - Настройки задаются в [config.json](../config.json).
  - Программа напрямую обращается к Immich API и LM Studio.
