# Настройка и запуск Сетевого Воркера (Worker)

Сетевой Воркер подключается к общей сетевой папке `CaptionQueue` (например, `\\NAS\CaptionQueue`), забирает ожидающие фото, отправляет их в локальный **LM Studio** для формирования описания с помощью модели зрения (VLM), и сохраняет результат в папку `Out`.

Воркер не требует прямого доступа к серверу Immich и не использует API-ключ.

---

## 1. Подготовка LM Studio и модели

1. Скачайте и установите [LM Studio](https://lmstudio.ai/).
2. Перейдите во вкладку поиска моделей (Search) и найдите подходящую VLM-модель (Vision Language Model).
   
   **Рекомендуемые модели**:
   - `Qwen/Qwen2.5-VL-7B-Instruct-GGUF` (квантование `Q4_K_M` или `Q5_K_M`) — великолепное распознавание русского языка, мелких деталей, вывесок, чеков и текста на фото. Требует около 6–8 ГБ VRAM.
   - `Qwen/Qwen3-VL-8B` (или аналогичные обновленные веса Qwen-VL).
   - Для более компактных GPU (4–6 ГБ VRAM): `Qwen/Qwen2.5-VL-3B-Instruct-GGUF`.

3. Загрузите модель в память GPU (в настройках укажите **GPU Acceleration: Max**).
4. Перейдите во вкладку **Developer / Local Server**:
   - Порт: `1234` (по умолчанию).
   - Нажмите кнопку **Start Server**.
   - Убедитесь, что сервер доступен по адресу `http://localhost:1234/v1`.

---

## 2. Использование графического приложения (`ImmichCaptionWorker.exe`)

Графический воркер разработан специально для комфортной фоновой работы на пользовательском ПК.

### Преимущества GUI-версии:
- **Дашборд**:
  - Карточки статистики: сколько фото в очереди `In/`, сколько обработано за сессию, текущая скорость (фото/мин и фото/час), среднее время генерации.
  - Живой график нагрузки GPU (с линией порога троттлинга) и счётчик видеопамяти VRAM.
  - Окно предпросмотра: отображает превью фото, которое сейчас распознается или было только что обработано, а также полученный текст описания с тегами.
- **Интеграция с треем**:
  - При закрытии крестиком окно плавно скрывается в область уведомлений (System Tray).
  - В контекстном меню трея можно быстро посмотреть текущую скорость, поставить обработку на паузу или вернуть окно на экран.
- **Автозагрузка**:
  - Галочка «Автозагрузка» прописывает запуск приложения с ключом `--minimized` в реестр Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`). При входе в Windows приложение стартует тихо, свернувшись в трей.
- **Вкладка настроек**:
  - Кнопка «Обзор...» для комфортного выбора сетевой папки очереди.
  - Кнопка «Тест связи» для проверки подключения к LM Studio.
  - Регулировка лимита нагрузки GPU (по умолчанию 35%).
  - Список тяжёлых процессов, при запуске которых воркер уходит в режим ожидания.

### Запуск:
Просто запустите [ImmichCaptionWorker.exe](../ImmichCaptionWorker.exe). Если запуск происходит из исходников Python:
```bash
python ui_worker.py
```

## 3. Консольный режим (`file_worker.py` / `run_file_worker.bat`)

Если требуется запустить воркер без графического интерфейса (например, в фоновом скрипте, на сервере или в терминале):
1. Отредактируйте [worker_config.json](../worker_config.json).
2. Запустите:
   ```cmd
   run_file_worker.bat
   ```
   или напрямую:
   ```cmd
   python file_worker.py
   ```

## 4. Конфигурация воркера (`worker_config.json`)

```json
{
  "queue": {
    "base_dir": "\\\\NAS\\CaptionQueue",
    "in_dir_name": "In",
    "out_dir_name": "Out",
    "poll_interval_seconds": 3
  },
  "lm_studio": {
    "url": "http://localhost:1234/v1",
    "model": "qwen2.5-vl-7b-instruct",
    "temperature": 0.2,
    "max_tokens": 350
  },
  "throttling": {
    "max_gpu_util_percent": 35,
    "check_interval_busy_seconds": 15,
    "idle_delay_between_photos_seconds": 1,
    "require_user_idle_seconds": 0,
    "heavy_processes": [
      "cyberpunk2077.exe",
      "blender.exe",
      "unrealengine.exe"
    ]
  },
  "worker": {
    "id": "worker-rtx"
  }
}
```

- `base_dir`: сетевой UNC-путь к шаре (`\\\\NAS\\CaptionQueue`) или локальный путь.
- `worker.id`: уникальный идентификатор рабочей станции. Используется в суффиксе временного захвата файла (`.claim_<worker_id>_<ts>.tmp`), благодаря чему в очереди видно, какой именно компьютер выполняет работу.
