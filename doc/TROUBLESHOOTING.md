# Диагностика и устранение неполадок (Troubleshooting)

В данном руководстве собраны решения наиболее частых проблем при работе в обоих режимах.

---

## 1. Проблемы с сетевой папкой очереди (CaptionQueue / SMB)

### Симптом: Воркер пишет «Ошибка доступа к очереди: [WinError 5] Отказано в доступе» или «[WinError 67] Не найдено сетевое имя»
- **Причина**: На сервере Samba не настроены права на запись, либо Windows пытается подключиться под неверной учётной записью.
- **Решение**:
  1. На сервере проверьте права на физическую папку:
     ```bash
     chmod -R 0777 /mnt/storage/CaptionQueue
     chown -R nobody:nogroup /mnt/storage/CaptionQueue
     ```
  2. В `/etc/samba/smb.conf` убедитесь в наличии:
     ```ini
     [CaptionQueue]
        path = /mnt/storage/CaptionQueue
        read only = no
        guest ok = yes
        force user = nobody
     ```
  3. Проверьте с ПК: откройте Проводник Windows -> `\\NAS\CaptionQueue`. Попробуйте создать текстовый файл и удалить его вручную.

## 2. Проблемы с LM Studio

### Симптом: Статус «Ожидание LM Studio (проверьте URL и модель)...»
- **Причина**: В LM Studio не нажат старт локального сервера, либо порт отличается от 1234.
- **Решение**:
  1. Откройте LM Studio -> вкладка с иконкой двусторонней стрелки `<->` (Developer / Server).
  2. Убедитесь, что сервер запущен (**Server Status: ON**).
  3. Проверьте адрес: по умолчанию `http://localhost:1234/v1`.
  4. Проверьте в браузере: откройте `http://localhost:1234/v1/models` — должен вернуться JSON-список с загруженной моделью.
  5. В настройках `ImmichCaptionWorker.exe` нажмите кнопку «Тест связи».

### Симптом: LM Studio падает с ошибкой Out Of Memory (OOM) / CUDA Out of Memory
- **Причина**: Слишком длинный контекст или не хватает VRAM под разрешение картинки и модель.
- **Решение**:
  1. Используйте модель меньшего квантования (например, `Q4_K_M` вместо `Q8_0`) либо модель размером 3B параметров (`Qwen2.5-VL-3B-Instruct`).
  2. В настройках сервера LM Studio ограничьте `Context Length` до 4096 токенов.
  3. Убедитесь, что координатор передает картинки с размером `"thumbnail_size": "preview"` (а не полный оригинал RAW/48MP).

### Симптом: Модель возвращает пустое описание
- **Причина**: В некоторых моделях reasoning/thinking (например, DeepSeek-R1-VL или экспериментальных ветках) весь вывод попадает в блок `<think>...</think>`, а финального ответа нет.
- **Решение**: Рекомендуется использовать официальные Vision-модели `Qwen/Qwen2.5-VL-7B-Instruct-GGUF` или `Qwen3-VL`, которые строго следуют формату ответа.

## 3. Зависшие блокировки задач (Stale Claims)

### Симптом: В папке `In/` лежат файлы вида `<id>.claim_said-home_1727210000.tmp`, и они не обрабатываются
- **Причина**: Воркер был экстренно закрыт во время распознавания (например, перезагрузка ПК или завершение через Диспетчер задач).
- **Решение**:
  - Координатор автоматически разблокирует такие файлы, если прошло более `stale_claim_timeout_minutes` (по умолчанию 15 минут).
  - Если нужно очистить блокировки вручную немедленно: просто переименуйте файл обратно в `<id>.jpg` или удалите суффикс `.claim_*.tmp`.

## 4. Троттлинг и ложные паузы

### Симптом: Воркер всё время пишет «Пауза: GPU нагружен: 42% (лимит: 35%)»
- **Причина**: Фоновые программы (браузер с аппаратным ускорением, видеоплеер, Wallpaper Engine) создают базовую нагрузку на GPU.
- **Решение**:
  1. В настройках воркера поднимите `max_gpu_util_percent` до `45`–`50%`.
  2. Если у вас несколько видеокарт, `nvidia-smi` опрашивает первую по списку. Убедитесь, что в LM Studio и мониторе используется нужная видеокарта.

### Симптом: «Обнаружен ресурсоёмкий процесс: ...»
- **Причина**: Запущен процесс из списка `heavy_processes` (например, открыт Blender или Unreal Engine).
- **Решение**: Воркер бережно уступает ресурсы тяжёлым приложениям. Если вы хотите, чтобы распознавание продолжалось даже при открытом редакторе, удалите имя процесса из списка во вкладке «Настройки».

## 5. Проблемы с Immich

### Симптом: Координатор пишет «Сбой API Immich: 401 Unauthorized»
- **Причина**: Неверный или истекший API-ключ.
- **Решение**:
  1. Зайдите в Immich Web UI.
  2. Нажмите на профиль (справа вверху) -> `Account Settings` -> `API Keys`.
  3. Создайте новый ключ и скопируйте его в `coordinator_config.json` (или `config.json`).
  4. Перезапустите координатор.

### Симптом: Описания сохраняются, но в поиске Immich они не находятся
- **Причина**: Сервер Immich индексирует текстовые метаданные в фоновом режиме через сервис Machine Learning / Search Indexer.
- **Решение**:
  1. В Immich Web UI перейдите в панель администратора: `Administration` -> `Jobs`.
  2. Запустите джобу `Search Indexing` (или `Facial Recognition` / `Smart Search`).
