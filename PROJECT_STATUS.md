## 1. Архитектура и принцип работы

Система решает ключевые задачи фотоархива Immich:
1. **Качественное нейросетевое распознавание и тегирование** через локальные модели Vision-Language (Qwen2.5-VL / Qwen3-VL в LM Studio на GPU NVIDIA).
2. **Раздельные языки для описаний и тегов**: генерация человекочитаемых описаний на родном языке пользователя (например, русском) и поисковых тегов на английском (или русском) для глобального поиска и совместимости с Adobe Lightroom, Bridge, PhotoPrism.
3. **Вечное сохранение метаданных в файлах (Source of Truth)**: вшивание стандартизированных IPTC/XMP метаданных прямо в оригинальные файлы через очередь ExifTool на сервере или локально. Опционально отключается чекбоксом на главном экране (запись только в базу Immich).
4. **Распределенный режим (Network Worker)**: возможность запуска воркеров на любых машинах локальной сети с мощными GPU для параллельной обработки очереди задач.

```
[ ПК Standalone (ui_app.py) ]
     │
     ├─► 1. Скачивает превью фото через Immich REST API (/api/search/metadata)
     ├─► 2. Поддерживает выборку по диапазону дат съемки (takenAfter / takenBefore)
     ├─► 3. Qwen-VL в LM Studio анализирует изображение
     ├─► 4. Обновляет Immich (/api/assets/{id}, /api/tags)
     └─► 5. [Опционально] Записывает задачу в очередь DropSync/ExifTool
                               │
                [ Домашний сервер cladovka (Linux) ]
                               │
                 apply_metadata.py (exiftool) ──► Вшивает IPTC/XMP в оригиналы
```

## 2. Что уже полностью реализовано

   - Интерфейс переведен на `ru`, `en`, `de`, `es`, `fr`, `ja`, `pt`, `zh`.
   - Динамическое разделение языков описания и тегов (`caption_language`, `tags_language`).

6. **Рефакторинг кнопки «Переделать всё» и удаление «Воркер сервера»**:

7. **Тестовый режим в Воркере (`ImmichAI_Captioner_Worker.exe`)**:

8. **Система всплывающих подсказок (ToolTips)**:
